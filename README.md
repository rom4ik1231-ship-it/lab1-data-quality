# Лабораторная работа №1 — Исследование и оценка качества данных

## О проекте
Аудит качества датасета [НАЗВАНИЕ] и разведочный анализ.

## Структура
- `data/` — исходные данные
- `notebooks/` — Jupyter Notebook с анализом
- `report/` — текстовый отчёт

## Как запустить
1. Установить зависимости: `pip install pandas numpy matplotlib seaborn jupyter`
2. Запустить: `jupyter notebook`
3. Открыть `notebooks/01_data_understanding.ipynb`
4. Выполнить все ячейки: Kernel → Restart & Run All
